# Katara - Project History

## Project Context

Moonwake is a concept-only deterministic tidal puzzle for HTML/CSS/vanilla
JavaScript/inline SVG, offline with no build step or runtime dependencies.
README is the brief; SVG is art. No simulation or test harness exists.

## Initial Knowledge - 2026-11-10

- Intended flow: preview lunar move, update tide, follow currents, reach harbor.
- Preview parity and undo/restart are intended contracts, not existing code.
- Moon positions, resolution order, cycles, and dawn budgets remain undecided.
- Squad onboarding authorizes no simulation implementation.
