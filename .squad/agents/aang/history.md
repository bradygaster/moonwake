# Aang - Project History

## Project Context

Moonwake has a README and original SVG concept art, not a playable UI.
The intended HTML/CSS/vanilla JavaScript/inline SVG game opens directly offline
with no build step, backend, or runtime dependencies.

## Initial Knowledge - 2026-11-10

- Visual direction: cobalt/sea-green paper layers, ochre islands, ivory moon,
  vermilion pennant, amber harbor lantern, engraved currents.
- Goals: keyboard, labels, non-color cues, text summaries, reduced motion.
- SVG coordinates are not a level contract. Avatar names are not game assets.
- Setup authorizes no shell, styling, or interaction implementation.
