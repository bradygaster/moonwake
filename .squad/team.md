## Project Context

- **Project:** moonwake
- **Created:** 2026-11-10
- **Status:** Concept only: README and original SVG art; no playable build or tests.
- **Goal:** Move the moon to change tides/currents, carrying a paper boat to harbor
  before dawn. Preview moves, then commit a deterministic turn.
- **Intended stack:** HTML, CSS, vanilla JavaScript, inline SVG. Direct-file,
  offline play; no build step, backend, or runtime dependencies.
- **UX:** Paper-layer nautical board, labeled keyboard controls, non-color cues,
  text turn summaries, reduced-motion equivalence, undo/restart.
- **Open:** Exact moon positions, budgets, current resolution, and levels still
  need design/playtesting. Intended capabilities are not implemented yet.
- **Sources:** `README.md` is the brief; `art/moonwake-concept.svg` is original
  concept art, not a gameplay screenshot or rule specification.
- **Setup:** Squad 2.0.0-preview.4, local state, no workflows or autonomous issue
  execution. See [contributor setup](../docs/squad.md).
